Bedakan verifikasi pembayaran dari proses pesanan pedagang.

Dua proses yang berbeda

1. Verifikasi pembayaran (Admin)

Admin memeriksa bukti transfer dan nomor referensi. Setelah disetujui, pembayaran menjadi Terverifikasi dan pesanan diteruskan ke pedagang. Jika ditolak, pesanan dibatalkan dan stok dikembalikan.

{% if is_admin %} Buka verifikasi pembayaran {% endif %}

2. Proses pesanan (Pedagang)

Pedagang tidak memverifikasi pembayaran. Setelah status pesanan menjadi Menunggu, pedagang mengonfirmasi untuk mulai menyiapkan pesanan, menandainya Siap diambil, lalu menyelesaikannya setelah pesanan diserahkan.

{% if is_vendor %} Buka pesanan pedagang {% endif %}

Arti status

  • Pembayaran: Menunggu Pembayaran — siswa belum mengirim bukti transfer.
  • Pembayaran: Menunggu Verifikasi Admin — bukti sudah dikirim, belum diperiksa.
  • Pembayaran: Terverifikasi — admin menyetujui pembayaran.
  • Pesanan: Menunggu — pembayaran sudah beres; pedagang dapat mulai memproses.
  • Pesanan: Diproses — pedagang sedang menyiapkan pesanan.
  • Pesanan: Siap diambil — siswa dapat mengambil pesanannya.
  • Pesanan: Selesai — pedagang mengonfirmasi pesanan telah diserahkan.

Status pembayaran menjawab “apakah uangnya sudah diperiksa?”, sedangkan status pesanan menjawab “sudah sampai tahap mana pesanan disiapkan atau diserahkan?”. Keduanya bukan persetujuan yang sama.

Alur siswa

  1. Pilih menu, masukkan ke keranjang, lalu checkout.
  2. Untuk GoPay, DANA, atau OVO, transfer ke nomor tujuan yang ditampilkan dan kirim bukti transfer.
  3. Tunggu Admin memeriksa pembayaran. Setelah disetujui, pedagang akan memproses pesanan.
  4. Pantau status di halaman Pesananku dan ambil pesanan setelah ditandai siap.
